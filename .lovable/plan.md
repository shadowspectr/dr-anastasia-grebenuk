

## План: Редизайн сайта по ТЗ — продающий лендинг для обучения косметологии

Полная переработка текущего сайта-визитки в одностраничный продающий лендинг с фокусом на курсы и обучение.

---

### Этап 1: База данных — новые таблицы

Создание миграции с таблицами под новую структуру:

- **`site_settings`** — герой-секция (заголовок, подзаголовок, фото, регалии), общие настройки
- **`social_proof`** — цифры доверия (лет опыта, выпускников, курсов)
- **`about_info`** — блок "Обо мне" (био, история, регалии, достижения)
- **`courses`** — карточки курсов (название, описание, формат, длительность, цена, бейдж, уровень)
- **`training_steps`** — шаги обучения (иконка, текст, порядок)
- **`reviews`** — отзывы выпускников (имя, фото, текст, специализация)
- **`student_works`** — портфолио работ учеников (фото до/после, курс)
- **`faq`** — FAQ (оставляем, уже есть в миграциях)
- **`contact_info`** — контакты, соцсети, мессенджеры
- **`applications`** — заявки с формы (имя, телефон, курс)

Storage bucket: `site-images` для фото.

Старые таблицы (main_content, team_members, services, gallery и т.д.) будут созданы заново с новой структурой.

---

### Этап 2: Новый дизайн и компоненты

**Цветовая палитра**: белый, пудровый розовый (#F5E6E0), глубокий розово-бордовый (#8B3A4A), светло-серый, антрацит.

**Новые компоненты** (mobile-first):

1. **StickyHeader** — фиксированная шапка с якорной навигацией + бургер-меню на мобилке + кнопка "Записаться"
2. **HeroSection** — имя, регалии, заголовок, CTA-кнопка, профессиональное фото
3. **SocialProofSection** — иконки с цифрами (опыт, выпускники, курсы)
4. **AboutMeSection** — фото + история + регалии + достижения
5. **CoursesSection** — карточки курсов с бейджами, фильтрами по уровню/формату, кнопки "Подробнее" и "Записаться"
6. **TrainingProcessSection** — пошаговый визуал: запись → оплата → обучение → сертификат
7. **ReviewsSection** — карусель отзывов с автопрокруткой
8. **StudentWorksSection** — галерея до/после с лайтбоксом
9. **FAQSection** — аккордеон (обновляем существующий)
10. **ApplicationForm** — форма заявки (имя, телефон, курс) + иконки мессенджеров
11. **Footer** — логотип, соцсети, контакты, политика конфиденциальности
12. **FloatingMessenger** — плавающая кнопка мессенджера в правом нижнем углу

**Удаляемые компоненты**: TeamSection, ServicesSection, WorksSection, BookingPage, PricePopup, BookingMethodDialog и связанные.

---

### Этап 3: Админ-панель

Обновление админ-панели для управления всеми новыми блоками:
- Редактирование hero, about, курсов, шагов, отзывов, FAQ, контактов
- Загрузка изображений
- Просмотр заявок

---

### Этап 4: SEO и производительность

- Обновление мета-тегов и structured data под обучение
- Lazy loading изображений
- Плавная прокрутка к секциям
- Pop-up с предложением через 30 секунд

---

### Техническая реализация

- Одна миграция для всех новых таблиц + RLS-политики (публичный SELECT, полный доступ для управления)
- Обновление `tailwind.config.ts` с новой палитрой
- Полная замена `Index.tsx` новой структурой блоков
- Сохранение edge-функций (check-availability, send-booking) если нужна интеграция с календарём для записи на курсы
- Форма заявки сохраняет данные в таблицу `applications` + опционально отправка на email через edge function
